## Installation

1. Download the universal macOS DMG and, if desired, verify its accompanying SHA-256 checksum.
2. Open the DMG and drag **Handwriting Eraser.app** into Applications.
3. This build is **not notarized by Apple**. If macOS blocks it, open **System Settings → Privacy & Security → Open Anyway** after verifying that you trust the download.
4. On first use, install the local handwriting detector (about 176 MB).

Requires macOS 15 or later; supports Apple silicon and Intel. PDF pages stay on your Mac.

Review output carefully: handwriting may remain or printed content may be removed. PDFs are exported as rasterized pages; this is not a redaction tool.
